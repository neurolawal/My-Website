# Overview

Vofa is an experimental neural signal decoder interface designed for low-latency processing and real-time visualization of sensory input data.

## Key Features

- **Low-Latency Streaming**: Real-time signal acquisition and filtering.
- **Adaptive Canvas**: Visual feedback tailored for experimental trials.
- **Interface Ergonomics**: Minimal friction layout designed for focused neural monitoring.

## Research Context

Understanding how sensory signals transfer across cortical layers requires tight coupling between real-time data streams and responsive visual controls. Vofa explores this intersection through lightweight frontend architecture and low-overhead signal visualization.
